# As One

This project features 80+ handmade puzzles, each with new surprises and mechanics, a level editor, and a level menu for selecting, moving, and deleting puzzles. The endgame remains unfinished, but the design is otherwise complete.

Cells in the puzzle grid are 16-bit values storing both entities (high bits) and tiles (low), which are saved into and read from a binary file.
