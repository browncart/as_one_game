# As One

The code for this game is very old. I wrote it before I understood C, just to get away from Unity. Most of it is sloppy and a little buggy. Still, this project has 80+ levels of not terrible quality, a level editor, and a level menu for selecting, moving, and deleting puzzles.

Cells are 16-bit values storing both entities and tiles, which are saved into and read from a binary file.
